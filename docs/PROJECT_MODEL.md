# Project Model

The active public model is a **curated, public-safe architectural context** derived from authoritative repository and runtime evidence.

It is not generated mechanically from private implementation and it is not a development-state ledger.

- [Current public model](project-model/project-model-public.md)
- [Project-model directory and maintenance rules](project-model/README.md)
- [Dated public snapshots](project-model/)
- [ADR-011 - GitHub as Development Source of Truth](adr/ADR-011-github-development-source-of-truth.md)

GitHub Issues and Git remain authoritative for development state and merged implementation. Releases/tags/workflows provide release evidence. Live systems provide runtime truth.

The public repository does not store the private Alfred implementation or private operational model.
