# Historical Archive

This directory contains public-safe historical records from before or outside the current Keriol Home / Butler architecture.

The files are preserved as **historical evidence**, not current operational documentation.

Start with the portfolio-wide [Historical Records index](../docs/HISTORICAL_RECORDS.md) for context, chronology and links to related worklogs, ADRs, project-model snapshots and retired workflow records.

## Current contents

- [April 2026 pre-Alfred home-automation model](home-automation-model-2026-04-pre-alfred-agent.md)

This snapshot predates the current Butler Core -> Wilfred -> Alfred layering and should be read as evidence of the system that existed before Alfred became a coherent private orchestration layer.

## Preservation rule

Historical records are not silently rewritten to match current architecture. When a record is superseded, the current documentation and the Historical Records index provide the modern interpretation while the original record remains available for traceability.
